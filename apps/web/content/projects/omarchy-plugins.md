Five plugins for the Omarchy shell. Omatop, Fizzy, Blast and Hydrate are listed in the [Omarchy plugin marketplace](https://plugins.omarchy.org). Omaday is not listed there; it installs from its repo.

- **Omatop**, the [system monitor](/projects/omatop): [ryanyogan/omarchy-omatop](https://github.com/ryanyogan/omarchy-omatop)
- **Omaday**, a calendar: [ryanyogan/omarchy-omaday](https://github.com/ryanyogan/omarchy-omaday)
- **Fizzy**, the kanban: [ryanyogan/omarchy-fizzy](https://github.com/ryanyogan/omarchy-fizzy)
- **Blast**, a block game with a live global leaderboard on Workers + D1: [ryanyogan/omarchy-blockblast](https://github.com/ryanyogan/omarchy-blockblast), with the leaderboard server in [ryanyogan/blockblast-server](https://github.com/ryanyogan/blockblast-server)
- **Hydrate**, a water tracker: [ryanyogan/omarchy-hydrate](https://github.com/ryanyogan/omarchy-hydrate)
