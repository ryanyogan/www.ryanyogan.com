A terminal coding agent I built from first principles to understand how these harnesses actually work. It is the second iteration of an earlier harness called Nightcode.

## What Is In It

- A streaming agent loop
- Seven tools
- Plan and build modes. Plan mode withholds the write tools, so planning cannot edit anything.
- Per-model thinking budgets
- Persisted interrupts

## Status

A public prototype.
