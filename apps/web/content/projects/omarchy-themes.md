An independent gallery of themes for Omarchy, live at [omarchythemes.dev](https://omarchythemes.dev). It is not run by the Omarchy project.

## What Is On It

- **Themes.** Search and filter the collection, click a theme to see it on a simulated desktop, and wear its palette across the whole site.
- **Backgrounds.** Every wallpaper in the catalog on one page, credited to the theme it came from.
- **Leaderboard.** Rankings from anonymous ratings.
- **Studio.** Build a palette, check its contrast, and get an install command for it.
- **Docs.** How an Omarchy theme is put together and how to publish one.

On October 4, 2026 the site listed 170 themes and 812 backgrounds.

## How It Is Built

TanStack Start on Cloudflare Workers, with the catalog in D1.

## Status

Live. The source is private.
