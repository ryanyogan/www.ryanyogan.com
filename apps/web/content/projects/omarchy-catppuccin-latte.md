I wrote the Catppuccin Latte theme that was merged into Omarchy in July 2025 ([omacom/omarchy#212](https://github.com/omacom/omarchy/pull/212)).

In 2026 I redid it. The refresh lives in its own repo and installs with one command:

```bash
omarchy theme install https://github.com/ryanyogan/omarchy-catppuccin-latte-theme
```

## What Is In It

- A slightly warmer base than stock Latte, with softer window borders
- Twelve wallpapers
- Contrast measurements for the text and accent colors, checked in to the repo
- Color refinements for btop, VS Code, Obsidian and a few coding agents

It is a community adaptation of [Catppuccin Latte](https://catppuccin.com/palette/), not an official Catppuccin release.

Public. A pull request to list it on the Omarchy site is open: [omacom/omarchy-site#390](https://github.com/omacom/omarchy-site/pull/390).
